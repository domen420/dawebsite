Before You Write

What to Include

Concrete figures in the first message save a round of questions and get you to a system proposal sooner.

[01]

Room & Application

  • Dimensions: length, width, ceiling height
  • Treatment: absorption and diffusion in place
  • Seating distance: main listening position
  • Use case: mastering, post, cinema, touring, install
[02]

Target Performance

  • SPL: continuous and peak at the listener
  • Bandwidth: required low-frequency extension
  • Headroom: margin above programme level
  • Coverage: horizontal and vertical pattern
[03]

Existing Chain

  • Amplification: model, power, load rating
  • DSP: processor and crossover in use
  • Sources: analogue, AES, Dante or other
  • Cabling: gauge and run lengths
